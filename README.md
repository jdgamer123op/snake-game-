🐍 Tkinter Python Snake Game
A classic Snake Game built with Python and Tkinter GUI, created by Gagandeep Singh Rathore.
This project demonstrates game development fundamentals such as event handling, collision detection, and dynamic rendering using Tkinter.

🎮 Features
Smooth gameplay with arrow keys or WASD controls.
Dynamic snake growth when eating food.
Increasing difficulty: game speed accelerates as the snake grows.
Score tracking with live updates.
Restart option via button or pressing R after game over.
Clean and modern UI with customizable colors.
🛠 Requirements
Python 3.x
Tkinter (comes pre-installed with Python)
No external dependencies required.
▶️ How to Run
Clone or download this repository.
Save the script as snake_game.py.
Run the game:
python snake_game.py

Use Arrow Keys or WASD to control the snake:
⬆️ / W → Up
⬇️ / S → Down
⬅️ / A → Left
➡️ / D → Right
📸 Gameplay Preview

Snake moves across a grid-based canvas.
Red circles represent food.
Snake grows longer and faster with each food eaten.
Game ends when the snake collides with walls or itself.
Final score is displayed with a restart option.
🧩 Code Highlights

Deque used for efficient snake body management.
Canvas for rendering snake and food.
after() loop for smooth game updates.
Collision detection for walls and self-intersection.
Restart functionality without restarting the program.
